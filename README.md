# A script for reversing and modifying your own game data in STS


What does this mean? It's a tool for editing your data through the "data/data" folders. Shiva stores it in .sts format. This is in android: ***Data/Data/com.shivagame.xd/app_home/Saves/##.sts*** 

## With **root** and **Termux** you can easily replace files!

## WARNING ⚠️ 
If the first packer and unpacker do not work, use: **unpacker2.py**, **packer2.py**
